Dúvidas Frequentes

O teste é grátis mesmo?

Sim! Você tem 5 dias de acesso total sem precisar cadastrar nenhum meio de pagamento agora.

Como faço para adicionar um colaborador?

Basta acessar a opção EMPRESA nos 3 pontinhos, adicionar um nome e senha e pronto!

Como funciona o fluxo de pedidos?

Para o uso do sistema é necessario no minimo dois celulares, um com o garçom que fará o pedido
e um na cozinha, o pedido feito pelo garçom apita na cozinha em menos de 5 segundos!

É um cardapio para o cliente?

Não, o sistema é uma comanda online para o uso dos colaboradores.

Como adicionar os pratos no sistema?

Basta acessar a opção COMFIGURAÇÃO nos 3 pontinhos, adicionar o nome do prato, valor e pronto!

Como funciona a tela MEUS PEDIDOS?

A tela serve para o garçom acompanhar o pedido realizado para a cozinha
quando a cozinha terminar o peido aparecerá nessa tela para que o garçom
possa ir até a cozinha para retirar o prato sem perca de tempo.
